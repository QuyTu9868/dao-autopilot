# Surface brief: DAO Autopilot app (frontend)

Mode: Operate. Single-page web app, English UI, desktop and phone widths. Build path: code-led.

Audience and job: hackathon judges and DAO token holders with a fresh test wallet. They finish setup (connect, mint, create voter, delegate, write policy), post a test proposal, and watch it get read, judged and voted.

Constraints: Base Sepolia only. Each step waits for the previous. Wallet rejection handled. No em dashes in copy.

Unresolved: none.

## Direction contract

THESIS: The app is a trail map. Every proposal is a route with four stops (Posted, Read by AI, Verdict, Voted) over flat coastline colour, so cause and effect is visible as a path. Refuses the dark neon wallet dashboard of cards and glowing stats.

OWN-WORLD: Cream ground #F5F1E4 as water, apple green #8ED462 as land lobes, ink #2C2E2A. Capsule controls in yellow #F5E211, coral #FF705D, blue #2BA0FF, lilac #EBC1FF. One grotesk at one weight, display at tight leading. Flat unmodulated fills, no grain, no gradients. State colour: green For, coral Against, lilac Skip, yellow pending, blue info.

STORY: A stranger sees what is missing and the one step that fixes it, completes setup in order, writes a plain-language policy, posts a proposal, and sees the AI's reason and the vote land within a minute, each step linked on-chain.

FIRST VIEWPORT: Top bar with name, network chip, connect button. Left pane "Your autopilot": five setup stops as a vertical route on a green lobe, only the current stop open with its single capsule action, later stops locked with the reason. Right pane "Proposals": post-a-proposal capsule and the list; each proposal row is a horizontal four-stop trail with the AI reason under it. Primary action sits at the current setup stop.
